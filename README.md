# Portfolio

Personal developer portfolio website.

**Live:** [dev.prasadrawas.online](https://dev.prasadrawas.online)

## Built With

- HTML5, CSS3, JavaScript (vanilla, no frameworks)
- Responsive design with dark theme
- GitHub Pages deployment

## Features

- Project showcase with detail pages
- Work experience timeline
- Tech stack section with experience chart
- Resume page with print-to-PDF export
- SEO optimized with JSON-LD structured data
- Preloader animation and cursor glow effects

## Project Structure

```text
.
├── index.html                  # Main portfolio landing page
├── project.html                # Project deep-dive detail view
├── CNAME                       # Custom domain (dev.prasadrawas.online)
├── sitemap.xml                 # Search engine sitemap
├── robots.txt                  # Search crawler directives
├── google88c5310f15fe53c8.html # Google Search Console verification
├── assets/
│   ├── css/                    # Stylesheets (style.css, project-detail.css)
│   ├── js/                     # Application logic & projects catalog data
│   └── images/                 # Profile photo, project logos, favicons, OG banner
├── resumes/                    # Resume hub & tailored resume variants
└── docs/                       # Internal asset generation & developer notes
```
