# Portfolio

Personal developer portfolio website.

**Live:** [dev.prasadrawas.online](https://dev.prasadrawas.online)

## Built With

- HTML5, CSS3, JavaScript (vanilla, no frameworks)
- Responsive design with dark theme
- GitHub Pages deployment

## Features

- Project showcase with detail pages
- Work experience timeline
- Tech stack section with experience chart
- Resume page with print-to-PDF export
- SEO optimized with JSON-LD structured data
- Preloader animation and cursor glow effects
