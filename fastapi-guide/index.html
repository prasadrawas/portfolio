Module 01

The Engine & Architecture: ASGI, Uvicorn & Starlette

To master FastAPI, you must understand that FastAPI itself does not listen on a network socket or parse raw HTTP bytes. It is the topmost developer layer in a 3-tier architecture:

1. Uvicorn (The ASGI Server): Written with C-based uvloop and httptools. It binds to the TCP socket (e.g. 0.0.0.0:8000), parses raw HTTP/1.1 or WebSocket bytes, and passes them downstream as structured dictionary events.

2. Starlette (The Web Framework Toolkit): Handles routing, HTTP request/response abstractions, cookie parsing, sessions, and WebSockets. FastAPI is literally a subclass of Starlette (class FastAPI(Starlette)).

3. FastAPI (The Productivity Engine): Adds Pydantic data validation, automatic OpenAPI/Swagger (/docs) documentation generation, and the Dependency Injection system (Depends).

The Raw ASGI Contract

Any valid ASGI app is simply an async callable taking 3 arguments: scope, receive, and send:

raw_asgi.py 
async def app(scope, receive, send):
    # scope contains request metadata (type: 'http', path: '/items', headers)
    if scope["type"] == "http":
        await send({
            "type": "http.response.start",
            "status": 200,
            "headers": [[b"content-type", b"text/plain"]],
        })
        await send({
            "type": "http.response.body",
            "body": b"Hello from pure raw ASGI!",
        })
AI Gotcha: Uvicorn in Production

AI models often suggest running uvicorn main:app --reload in production Dockerfiles. Never do this! --reload runs a file watcher thread that leaks memory and hurts CPU performance. In production, run without --reload and configure worker count: uvicorn main:app --host 0.0.0.0 --port 8000 --workers 4.

routes_demo.py 
from fastapi import FastAPI, Path, Query, Header, UploadFile, File
from pydantic import BaseModel

app = FastAPI()

class ItemPayload(BaseModel):
    name: str
    price: float

@app.post("/stores/{store_id}/items")
async def create_store_item(
    store_id: int = Path(..., ge=1, description="Store DB primary key"),
    category: str = Query("general", min_length=2),
    payload: ItemPayload = ...,  # Request JSON body
    x_client_version: str | None = Header(None)
):
    return {
        "store": store_id,
        "category": category,
        "item": payload.model_dump(),
        "version": x_client_version
    }

@app.post("/upload-avatar")
async def upload_avatar(file: UploadFile = File(...)):
    # UploadFile stores large files in a temporary spooled file on disk
    # preventing memory exhaustion from 50MB uploads
    contents = await file.read()
    return {"filename": file.filename, "size_bytes": len(contents)}
Module 03

Pydantic v2 Core: Validation, Coercion & Serialization

Pydantic v2 was rewritten in **Rust** (pydantic-core) and is 5–50x faster. It performs runtime type coercion, raises detailed ValidationError exceptions, and powers FastAPI's request validation.

pydantic_v2_core.py 
from pydantic import BaseModel, Field, field_validator, model_validator
from datetime import datetime

class UserRegister(BaseModel):
    username: str = Field(min_length=3, max_length=20, pattern="^[a-zA-Z0-9_]+$")
    email: str
    age: int = Field(ge=18, le=120)
    created_at: datetime = Field(default_factory=datetime.utcnow)

    # Custom field validator (Pydantic v2 syntax)
    @field_validator("email")
    @classmethod
    def validate_email_domain(cls, v: str) -> str:
        if "@" not in v:
            raise ValueError("Invalid email format")
        return v.lower()

    # Multi-field model validator
    @model_validator(mode="after")
    def check_admin_age(self) -> "UserRegister":
        if self.username.startswith("admin_") and self.age < 21:
            raise ValueError("Admins must be at least 21 years old")
        return self
AI Gotcha: .dict() vs .model_dump()

Old tutorials and outdated AI code use user.dict() and user.json(). In Pydantic v2, these are deprecated! Always use user.model_dump() (for a dictionary) and user.model_dump_json() (for a JSON string).

Module 04

Advanced Pydantic: Generic Envelopes, ConfigDict & Computed Fields

In professional APIs, you rarely return bare objects or arrays. You return structured response envelopes with metadata, pagination, and error fields.

advanced_pydantic.py 
from typing import Generic, TypeVar
from pydantic import BaseModel, ConfigDict, computed_field

T = TypeVar("T")

# Standard Generic API Envelope
class APIResponse(BaseModel, Generic[T]):
    success: bool = True
    data: T
    message: str | None = None

class UserEntity(BaseModel):
    # from_attributes=True enables converting SQLAlchemy ORM objects into Pydantic models
    model_config = ConfigDict(from_attributes=True, str_strip_whitespace=True)

    id: int
    first_name: str
    last_name: str

    @computed_field
    def full_name(self) -> str:
        return f"{self.first_name} {self.last_name}"

# Usage in FastAPI route:
@app.get("/users/{user_id}", response_model=APIResponse[UserEntity])
def get_user(user_id: int):
    user_db = fetch_user_from_db(user_id)
    return APIResponse(data=user_db)
Module 05

Response Handling, Status Codes & Global Exception Handlers

Avoid returning {"status": "error"} with an HTTP 200 OK! Use proper HTTP semantics with HTTPException and register global handlers for database errors or unhandled exceptions.

exception_handlers.py 
from fastapi import FastAPI, Request, HTTPException, status
from fastapi.responses import JSONResponse

app = FastAPI()

class EntityNotFoundError(Exception):
    def __init__(self, entity_name: str, entity_id: int):
        self.entity_name = entity_name
        self.entity_id = entity_id

# Global Exception Handler catches EntityNotFoundError from ANY route
@app.exception_handler(EntityNotFoundError)
async def entity_not_found_handler(request: Request, exc: EntityNotFoundError):
    return JSONResponse(
        status_code=status.HTTP_404_NOT_FOUND,
        content={
            "error": "RESOURCE_NOT_FOUND",
            "message": f"{exc.entity_name} with ID {exc.entity_id} was not found",
            "path": request.url.path
        }
    )

@app.get("/orders/{order_id}")
async def get_order(order_id: int):
    if order_id > 100:
        raise EntityNotFoundError(entity_name="Order", entity_id=order_id)
    return {"order_id": order_id, "status": "shipped"}
Module 06

The Superpower: Dependency Injection (Depends)

Dependency Injection in FastAPI is simple yet extraordinarily powerful. It resolves dependencies hierarchically and handles automatic resource cleanup via Python's yield syntax:

dependencies.py 
from fastapi import FastAPI, Depends, Header, HTTPException

app = FastAPI()

# 1. Yield Dependency (Database session lifecycle)
async def get_db_session():
    db = create_connection()
    try:
        yield db  # Code executes before route
    finally:
        db.close()  # ALWAYS runs after route finishes (even on errors!)

# 2. Reusable Auth Guard
async def get_current_user(x_api_key: str = Header(...)):
    if x_api_key != "secret-123":
        raise HTTPException(status_code=401, detail="Invalid API Key")
    return {"user_id": 1, "role": "admin"}

# 3. Route injecting both dependencies cleanly
@app.get("/dashboard")
async def view_dashboard(
    user = Depends(get_current_user),
    db = Depends(get_db_session)
):
    return {"message": f"Welcome {user['role']}!"}
Module 07

Async Mechanics: async def vs. Regular def

This is the #1 area where developers accidentally cripple FastAPI's performance. Knowing how FastAPI executes both styles is critical:

Route DeclarationWhere It ExecutesWhen to Use
async def route() Directly on the single Main Event Loop Only when using true async I/O with await (e.g. await db.fetch(), await httpx.get()).
def route() (standard) In an external Thread Pool (ThreadPoolExecutor) When using blocking synchronous libraries (e.g. standard requests.get(), synchronous DB queries, heavy file I/O).
The Fatal Mistake: Blocking Code in async def

If you write time.sleep(5) or requests.get(...) inside an async def route, you block the entire server's event loop. Every other concurrent user is completely frozen! If your library doesn't support await, declare the endpoint with regular def.

Concurrency Throttling with asyncio.Semaphore

semaphore_throttle.py 
import asyncio
from fastapi import FastAPI

app = FastAPI()
# Limit outbound requests to an external API (e.g. OpenAI) to 10 concurrent requests
semaphore = asyncio.Semaphore(10)

@app.post("/call-ai")
async def call_ai_service():
    async with semaphore:
        # At most 10 requests can execute this block at the same time
        response = await query_ai_model()
        return response
Module 08

Real-Time & Streaming: SSE for AI Tokens & WebSockets

In the AI era, users expect streaming responses (like ChatGPT). FastAPI implements this natively using StreamingResponse with Server-Sent Events (SSE).

ai_streaming.py 
from fastapi import FastAPI
from fastapi.responses import StreamingResponse
import asyncio

app = FastAPI()

async def ai_token_generator():
    tokens = ["Artificial ", "intelligence ", "is ", "transforming ", "software."]
    for token in tokens:
        await asyncio.sleep(0.3)  # Simulating LLM token inference delay
        yield f"data: {token}\n\n"  # SSE standard format

@app.get("/ai/stream")
async def stream_chat():
    return StreamingResponse(ai_token_generator(), media_type="text/event-stream")

Full-Duplex WebSockets

websocket_chat.py 
from fastapi import FastAPI, WebSocket, WebSocketDisconnect

app = FastAPI()

class ConnectionManager:
    def __init__(self):
        self.active_connections: list[WebSocket] = []

    async def connect(self, ws: WebSocket):
        await ws.accept()
        self.active_connections.append(ws)

    def disconnect(self, ws: WebSocket):
        self.active_connections.remove(ws)

    async def broadcast(self, message: str):
        for connection in self.active_connections:
            await connection.send_text(message)

manager = ConnectionManager()

@app.websocket("/ws/{client_id}")
async def websocket_endpoint(websocket: WebSocket, client_id: str):
    await manager.connect(websocket)
    try:
        while True:
            data = await websocket.receive_text()
            await manager.broadcast(f"{client_id}: {data}")
    except WebSocketDisconnect:
        manager.disconnect(websocket)
        await manager.broadcast(f"{client_id} left the chat")
Module 09

Modern Lifespan Context & Custom Middleware

In modern FastAPI, the old @app.on_event("startup") is deprecated. You manage application lifecycle (initializing database pools, ML models, and Redis connections) using Python's @asynccontextmanager:

lifespan_and_middleware.py 
from contextlib import asynccontextmanager
from fastapi import FastAPI, Request
from fastapi.middleware.cors import CORSMiddleware
import time

@asynccontextmanager
async def lifespan(app: FastAPI):
    # STARTUP: runs before the server accepts any requests
    print("Connecting to Database pool and Redis...")
    app.state.redis_pool = await create_redis_pool()
    yield
    # SHUTDOWN: runs on server stop
    print("Closing connections cleanly...")
    await app.state.redis_pool.disconnect()

app = FastAPI(lifespan=lifespan)

# 1. CORS Middleware
app.add_middleware(
    CORSMiddleware,
    allow_origins=["https://dev.prasadrawas.online"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

# 2. Custom Timing Middleware
@app.middleware("http")
async def add_process_time_header(request: Request, call_next):
    start_time = time.time()
    response = await call_next(request)
    duration_ms = (time.time() - start_time) * 1000
    response.headers["X-Process-Time-Ms"] = f"{duration_ms:.2f}"
    return response

Database Integration: SQLAlchemy 2.0 Async & N+1 Query Fixes

SQLAlchemy 2.0 modernizes Python ORM with strict type safety. It uses Mapped[] and mapped_column() instead of legacy column syntax:

database_sqlalchemy2.py 
from sqlalchemy.ext.asyncio import create_async_engine, async_sessionmaker, AsyncSession
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column, relationship, selectinload
from sqlalchemy import select, ForeignKey

# Async Engine & Sessionmaker
DATABASE_URL = "postgresql+asyncpg://user:pass@localhost:5432/production_db"
engine = create_async_engine(DATABASE_URL, pool_size=20, max_overflow=10)
AsyncSessionLocal = async_sessionmaker(bind=engine, class_=AsyncSession, expire_on_commit=False)

class Base(DeclarativeBase):
    pass

class User(Base):
    __tablename__ = "users"
    id: Mapped[int] = mapped_column(primary_key=True)
    email: Mapped[str] = mapped_column(unique=True, index=True)
    orders: Mapped[list["Order"]] = relationship(back_populates="user")

class Order(Base):
    __tablename__ = "orders"
    id: Mapped[int] = mapped_column(primary_key=True)
    user_id: Mapped[int] = mapped_column(ForeignKey("users.id"))
    total: Mapped[float]
    user: Mapped[User] = relationship(back_populates="orders")

# Fixing N+1 Query Problem: Use selectinload for 1-to-many relationships
async def get_users_with_orders(session: AsyncSession):
    stmt = select(User).options(selectinload(User.orders))
    result = await session.execute(stmt)
    return result.scalars().all()

Security, Authentication & Role-Based Access Control (RBAC)

FastAPI provides built-in integration with OpenAPI's security schemes via OAuth2PasswordBearer, which makes a working "Authorize" button appear directly inside Swagger UI (/docs).

auth_jwt.py 
from fastapi import FastAPI, Depends, HTTPException, status
from fastapi.security import OAuth2PasswordBearer
import jwt
from datetime import datetime, timedelta

SECRET_KEY = "your-secret-key-32-chars-minimum"
ALGORITHM = "HS256"
oauth2_scheme = OAuth2PasswordBearer(tokenUrl="/auth/token")

def create_jwt_token(data: dict, expires_delta: timedelta = timedelta(hours=1)):
    to_encode = data.copy()
    to_encode["exp"] = datetime.utcnow() + expires_delta
    return jwt.encode(to_encode, SECRET_KEY, algorithm=ALGORITHM)

async def get_current_user(token: str = Depends(oauth2_scheme)):
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
        username: str = payload.get("sub")
        role: str = payload.get("role", "user")
        if username is None:
            raise HTTPException(status_code=401, detail="Invalid token")
        return {"username": username, "role": role}
    except jwt.PyJWTError:
        raise HTTPException(status_code=401, detail="Token expired or invalid")

# Role-Based Access Control Factory Dependency
def require_role(required_role: str):
    def role_checker(current_user: dict = Depends(get_current_user)):
        if current_user["role"] != required_role:
            raise HTTPException(status_code=403, detail="Insufficient permissions")
        return current_user
    return role_checker

@app.delete("/admin/purge", dependencies=[Depends(require_role("admin"))])
def purge_system():
    return {"message": "System purged successfully"}

Background Processing: Built-in BackgroundTasks vs. Celery / ARQ

Understand when to use in-process background tasks versus distributed task queues:

FeatureFastAPI BackgroundTasksDistributed Queue (Celery / ARQ)
ExecutionSame Python process (in-memory)Separate dedicated worker processes
Crash Recovery❌ Lost if server restarts✅ Persisted in Redis / RabbitMQ broker
Heavy CPU tasks❌ Blocks server thread pool✅ Distributed across worker nodes
Best ForSending an email, writing a log lineVideo encoding, CSV bulk imports (10k+ rows)
background_tasks.py 
from fastapi import FastAPI, BackgroundTasks

app = FastAPI()

def send_welcome_email(email: str):
    # Runs AFTER the HTTP 200 response has already been returned to the client
    send_smtp_email(to=email, subject="Welcome to our Platform!")

@app.post("/register")
async def register_user(email: str, background_tasks: BackgroundTasks):
    save_user_to_db(email)
    background_tasks.add_task(send_welcome_email, email)
    return {"status": "Account created! Welcome email is sending."}

Module 14

Enterprise SRE: Structured JSON Logs, Correlation IDs & Metrics

In microservice architectures, an incoming request travels through load balancers, FastAPI services, and databases. You must stamp every request with a unique X-Request-ID and output structured JSON logs.

sre_observability.py 
from fastapi import FastAPI, Request
import uuid, json, logging

app = FastAPI()
logger = logging.getLogger("structured_logger")

@app.middleware("http")
async def correlation_id_middleware(request: Request, call_next):
    # Grab existing request ID or generate a new UUID
    request_id = request.headers.get("X-Request-ID", str(uuid.uuid4()))
    request.state.request_id = request_id

    response = await call_next(request)
    response.headers["X-Request-ID"] = request_id

    # Structured JSON log line for Datadog / CloudWatch
    log_data = {
        "request_id": request_id,
        "method": request.method,
        "path": request.url.path,
        "status": response.status_code
    }
    logger.info(json.dumps(log_data))
    return response

Automated Testing (Pytest + AsyncClient) & Production Dockerfile

How Senior Engineers test endpoints without launching a live network server, followed by a hardened multi-stage production Dockerfile:

test_endpoints.py 
import pytest
from httpx import AsyncClient, ASGITransport
from main import app

@pytest.mark.asyncio
async def test_create_item_success():
    # ASGITransport calls the FastAPI app in-memory with zero network overhead
    async with AsyncClient(transport=ASGITransport(app=app), base_url="http://test") as client:
        payload = {"name": "Gaming Monitor", "price": 299.99}
        response = await client.post("/items/", json=payload)
        
        assert response.status_code == 201
        data = response.json()
        assert data["name"] == "Gaming Monitor"
        assert "id" in data
